# Telecom-Complain-Escalation
Built a Decision Tree classification model to analyze telecom customer complaints and predict complaint status. Performed data preprocessing, exploratory data analysis, categorical encoding, model training, and evaluation using Python and Scikit-learn.

1. **Project Objective** – Built a machine learning model to analyze telecom customer complaints and classify their complaint status.

2. **Dataset** – Worked with a telecom complaint dataset containing **2,224 records and 11 features**, including complaint details, location, channel, and status.

3. **Data Exploration** – Used Pandas to inspect the dataset, understand data types, check missing values, and analyze the distribution of different features.

4. **Exploratory Data Analysis** – Created visualizations using Matplotlib and Seaborn to identify patterns between complaint status, location, and the channel through which complaints were received.

5. **Data Preprocessing** – Removed unnecessary columns such as Ticket Number, Customer Complaint, Date, and Time before building the machine learning model.

6. **Categorical Encoding** – Converted categorical variables into numerical values using **LabelEncoder** so they could be used by the machine learning algorithm.

7. **Feature Selection** – Prepared relevant features such as Received Via, City, State, Zip Code, and Filing on Behalf of Someone for model training.

8. **Machine Learning Model** – Implemented a **Decision Tree Classifier** using Scikit-learn to classify telecom complaint status.

9. **Model Evaluation** – Evaluated the model using **Accuracy Score, Classification Report, and Confusion Matrix** to measure its performance.

10. **Technologies Used** – Python, Pandas, NumPy, Matplotlib, Seaborn, and Scikit-learn were used for data analysis, visualization, preprocessing, and machine learning.
